# अनलाइन बजार · Open-Bazar
Deploy: upload the whole folder to Netlify (HTTPS). Cloud: Firebase project aazabo-bazar (Auth + Firestore). Rules: firestore.rules.
Admin: log in once first with the owner Gmail (claims admin in cloud). Customers: free. Merchants: Rs100 per 35 days (20 items) + Rs50 per extra 10 items; admin verifies payments.
APK: wrap the deployed HTTPS URL (PWABuilder/Bubblewrap TWA) or Capacitor.
